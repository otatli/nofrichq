Current Project

LifeOS

AI-powered personal operating system

LifeOS is a portfolio-grade product project designed to organize personal productivity, career development, health, finance and software projects in one place. The project is currently in development and is being built as both a real product experiment and a professional portfolio asset.

View GitHub Back to profile

Product Vision

A personal command center that helps users track goals, routines, career progress, software projects, finances and health-related habits without spreading information across many separate tools.

Why I am building it

LifeOS combines product thinking with modern frontend engineering. It is designed to demonstrate real-world development discipline: backlog management, sprint planning, issue-based delivery, testing, CI and clean documentation.

Initial Scope

  • Personal dashboard concept
  • Career and project tracking foundation
  • Sprint and backlog planning workflow
  • Modular frontend structure
  • Testing and CI setup foundation

Engineering Practices

  • GitHub Projects for roadmap and sprint tracking
  • Issue-based development workflow
  • ESLint and Prettier for code quality
  • Vitest and React Testing Library for frontend testing
  • GitHub Actions for automated checks

Technology Stack

React 19 TypeScript Vite Vitest React Testing Library ESLint Prettier GitHub Actions GitHub Projects

Status

LifeOS is in active early development. The current focus is establishing the frontend foundation, development workflow, project structure and portfolio-ready documentation.
